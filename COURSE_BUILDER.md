# Как создавать уроки курса

Все уроки хранятся в одном файле: `src/content/course.ts`  
Массив `LESSONS` — это и есть твой курс. Добавляй объекты `Lesson` в нужном порядке.

---

## Структура урока

```ts
{
  day: 11,                          // Номер дня (1–30), должен быть уникальным
  title: 'Название урока',          // Отображается в шапке урока
  objective: 'Чему научится',       // Цель урока (пока не отображается пользователю)
  estimatedMinutes: 20,             // Примерное время прохождения
  pdfFile: 'assets/lessons/day11.pdf',  // (опционально) PDF-конспект для этого дня
  steps: [ /* массив шагов */ ],
}
```

Поле `pdfFile` — необязательное. Если файл указан, бот отправит его пользователю автоматически перед первым шагом.

---

## Типы шагов

Каждый урок состоит из шагов (`steps`). Их можно миксовать в любом порядке.  
Всего 4 типа:

---

### 1. `explain` — объяснение

Просто показывает текст. Пользователь читает и нажимает **«Продолжить»**.  
Используй для новых правил, словарей, теорий.

```ts
{
  type: 'explain',
  title: '📖 Название блока',         // Заголовок (жирный, в шапке)
  text: 'Здесь основной текст...',    // Поддерживает HTML-теги: <b>, <i>, \n
  examples: [                          // (опционально) примеры под текстом
    { english: 'I am happy.', russian: 'Я счастлив.' },
    { english: 'She is tired.', russian: 'Она устала.' },
  ],
  audioFile: 'assets/audio/day11_explain.mp4', // (опционально) аудио-кружок
}
```

**HTML в тексте:** используй теги `<b>жирный</b>`, `<i>курсив</i>`, `\n` для переноса строки.

---

### 2. `choice` — выбор из вариантов

Пользователь видит вопрос и несколько кнопок. Выбирает один вариант.  
При неверном ответе — подсказка, кнопки остаются. При верном — объяснение и переход дальше.

```ts
{
  type: 'choice',
  question: '🎯 Вопрос для пользователя',
  options: ['Вариант A', 'Вариант B', 'Вариант C', 'Вариант D'],
  correctIndex: 1,              // Индекс правильного ответа (0 = первый)
  hint: 'Короткая подсказка',   // Показывается при НЕВЕРНОМ ответе
  explanation: 'Объяснение',    // Показывается при ВЕРНОМ ответе (поддерживает <b>, <i>)
  audioFile: 'assets/audio/day11_q1.mp4', // (опционально) кружок с вопросом
}
```

**Советы:**
- 3–4 варианта — оптимально
- `hint` — не раскрывай ответ, дай направление: *«Думай про she/it»*
- `explanation` — объясни правило, не просто скажи что правильно

---

### 3. `input` — текстовый ввод

Пользователь печатает ответ. Бот сравнивает его с эталоном.  
Есть два режима совпадения.

```ts
{
  type: 'input',
  question: '✏️ Переведи: «Она живёт в Москве.»',
  answerKey: [
    'she lives in moscow',        // Основной вариант
    "she's living in moscow",     // Допустимые альтернативы
  ],
  matchMode: 'exact',             // 'exact' (по умолчанию) или 'startsWith'
  hint: 'She + lives + место',
  explanation: '<b>She lives in Moscow.</b> — для she добавляем -s к глаголу.',
}
```

**`matchMode`:**

| Режим | Поведение |
|-------|-----------|
| `exact` (по умолчанию) | Ответ должен точно совпасть с одним из `answerKey` (с нормализацией) |
| `startsWith` | Ответ должен **начинаться** с одного из `answerKey` — удобно когда у пользователя есть своё имя в ответе |

**Нормализация** происходит автоматически: регистр игнорируется, знаки препинания в конце обрезаются, лишние пробелы убираются. Пиши `answerKey` в нижнем регистре без точки.

**Пример с `startsWith`:**
```ts
// Вопрос: «Напиши "My name is ..."»
answerKey: ['my name is'],
matchMode: 'startsWith',
// Подойдёт: "My name is Anna", "my name is Alex", "MY NAME IS MAX"
```

---

### 4. `free` — свободный ответ

Принимает **любой** текст от пользователя — не проверяет правильность.  
Показывает пример ответа и подсказку. Используй для творческих заданий, монологов, диалогов.

```ts
{
  type: 'free',
  question: '🗣 Расскажи о себе 3–4 предложениями.',
  exampleAnswer: 'Hi! My name is Anna. I\'m 25. I\'m from Russia. I\'m a student.',
  tip: 'Используй: I\'m... / My name is... / I\'m from...',
}
```

## Медиафайлы

### Аудио-кружок (`audioFile`)

Любой шаг может иметь поле `audioFile` — бот отправит **видео-кружок** перед шагом.  
Это должен быть `.mp4` файл, сжатый под кружок (≤ 1 мин, квадратный кадр).

```ts
audioFile: 'assets/audio/day11_greetings.mp4'
```

Путь — относительно корня проекта. Храни файлы в `assets/audio/`.  
Если файл не найден — бот просто пропустит кружок без ошибки.

**Именование:** `day{NN}_{описание}.mp4`, например:
- `day01_greetings.mp4` — кружок объяснения
- `day01_q1.mp4` — кружок к первому вопросу

### PDF-конспект (`pdfFile`)

Указывается на уровне урока (не шага). Отправляется один раз — перед первым шагом.

```ts
pdfFile: 'assets/lessons/day11.pdf'
```

Храни файлы в `assets/lessons/`. Если файл не найден — бот пропустит без ошибки.

## Полный пример урока

```ts
{
  day: 11,
  title: 'Глагол have: иметь',
  objective: 'Научиться говорить о владении',
  pdfFile: 'assets/lessons/day11.pdf',
  estimatedMinutes: 20,
  steps: [
    {
      type: 'explain',
      title: '📖 Глагол have / has',
      text:
        '• I/You/We/They + <b>have</b>\n' +
        '• He/She/It + <b>has</b>\n\n' +
        'Исключение: he/she/it → have → <b>has</b>',
      examples: [
        { english: 'I have a car.', russian: 'У меня есть машина.' },
        { english: 'She has a dog.', russian: 'У неё есть собака.' },
      ],
      audioFile: 'assets/audio/day11_have.mp4',
    },
    {
      type: 'choice',
      question: '🎧 Выбери правильный вариант:\n«He ___ two sisters.»',
      audioFile: 'assets/audio/day11_q1.mp4',
      options: ['have', 'has', 'is have', 'are have'],
      correctIndex: 1,
      hint: 'He → have или has?',
      explanation: '<b>He has</b> — для he/she/it глагол have меняется на has.',
    },
    {
      type: 'input',
      question: '✏️ Переведи:\n«У них есть дом.»',
      answerKey: ['they have a house'],
      hint: 'They + have + ...',
      explanation: '<b>They have a house.</b>',
    },
    {
      type: 'free',
      question: '🗣 Напиши 3 предложения о том, что есть у тебя и твоих близких.',
      exampleAnswer: 'I have a cat. My brother has a car. We have a small flat.',
      tip: 'I have / He has / She has / We have',
    },
  ],
},
```

## Рекомендуемая структура урока

Хорошая последовательность шагов для одного урока (5–6 шагов, 15–25 мин):

1. **`explain`** — объяснение правила + примеры *(+ аудио-кружок)*
2. **`choice`** — лёгкий вопрос на понимание *(+ аудио-кружок)*
3. **`choice`** или **`input`** — немного сложнее
4. **`input`** — перевод или вставить слово
5. **`input`** или **`choice`** — финальное закрепление
6. **`free`** — творческое задание (открытый ответ)

## Частые ошибки

| Ошибка | Как правильно |
|--------|--------------|
| `answerKey` с точкой в конце | Пиши без точки: `'she lives in moscow'` |
| `answerKey` с большой буквы | Пиши в нижнем регистре: `'i am happy'` |
| `correctIndex` не соответствует `options` | Индекс с нуля: первый вариант = `0` |
| Слишком длинный `hint` | Hint — 1 строка, без спойлера ответа |
| Пустой `explanation` | Всегда объясняй правило, даже коротко |
| Аудио в `.ogg` или `.mp3` | Только `.mp4` (видео-кружок Telegram) |

## Быстрый чеклист нового дня

- [ ] Добавил объект в массив `LESSONS` с уникальным `day`
- [ ] Указал `title`, `objective`, `estimatedMinutes`
- [ ] Добавил `pdfFile` если есть конспект
- [ ] В `steps` есть хотя бы 1 объяснение и 1-2 задания
- [ ] В каждом `choice` и `input` заполнены `hint` и `explanation`
- [ ] Аудио-файлы лежат в `assets/audio/` (если используются)
- [ ] PDF лежит в `assets/lessons/` (если используется)
